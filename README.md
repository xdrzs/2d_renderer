# Renderer 2D em OpenGL

Esse projeto nasceu de uma deficiência que eu encontrei tentando criar um renderer 2D e não achar muita coisa na internet sobre isso. Ainda mais em português.

Mesmo pensando nos materiais que eu usei de base, ainda senti uma dificuldade ao passo que eles deixavam algumas partes em aberto demais. Daí eu resolvi fazer o meu próprio e aprender no caminho.

O objetivo é que se alguém tiver tentando aprender mais fundalmentalmente como desenhar pixels em uma tela para um mundo 2D, esse projeto pode ajudar a esclarecer algumas dúvidas e ensinar também :)

Eu sei que OpenGL já tá bem defasado, mas eu precisava começar de algum lugar e não tô afim de ficar aprendendo Vulkan agora.
